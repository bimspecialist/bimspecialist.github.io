# BIM City Pro — Browser 3D Vertical Slice

هذه تجربة **قابلة للعب** تعتمد على Three.js r183 وWebGL، وليست لعبة AAA نهائية.

## التشغيل

الرابط المنشور: https://bimspecialist.github.io/arcade-forge-3d/bim-city-pro/

المتصفح: Chrome أو Edge أو Firefox أو Safari حديث يدعم WebGL. نسخة GitHub Pages تتضمن محرك Three.js محليًا في مجلد `vendor` لتقليل الاعتماد على CDN.

## التحكم

- 1 / 2 / 3: اختيار الحفّار أو الشاحنة أو الخلاطة.
- WASD أو الأسهم: قيادة المعدات.
- Q / E: رفع أو خفض ذراع الحفّار؛ R / F للذراع الثانية؛ Z / X للدلو.
- Space: حفر أو تحميل/تفريغ أو صب حسب الآلة وموضعها.
- V: تغيير الكاميرا، U: الترقيات، سحب الشاشة: تحريك الكاميرا، عجلة الفأرة: تقريب.
- الجوال: أزرار قيادة وتنفيذ وتغيير المعدة.

## اللعبة

1. احفر 12 م³ من التربة باستخدام الحفّار في منطقة العمل.
2. قد الشاحنة إلى منطقة التحميل ثم انقل التربة إلى منطقة التفريغ.
3. قد خلاطة الخرسانة إلى منطقة الأساسات، وصب 10 م³.
4. استلم مكافأة العقد وطور الهيدروليك والمحرك وكرر العقود.

يُحفظ التقدم آليًا في `localStorage` ضمن `arcade-forge-bim-siteops-pro-v1`، دون تغيير ملفات الحفظ للألعاب السابقة.

## خط إنتاج الرسومات

- المحرك: Three.js r183 محليًا، MIT. ملف الترخيص: `vendor/LICENSE-Threejs.txt`.
- المواد: `MeshStandardMaterial` و`MeshPhysicalMaterial` مع Base Color/Normal/Roughness Maps. الخرائط الأساسية **مولّدة إجرائيًا** في Canvas وليست فوتوغرافية.
- خامات اختيارية على الإنترنت: Poly Haven `gravel`، Diffuse + Normal (OpenGL) + Roughness، بترخيص CC0. عند فشل التحميل، تبقى الخامات الإجرائية.
- الإضاءة: Tone mapping وDirectional Shadows وAmbient/Hemisphere Lighting وضباب مشهدي.
- الأصول: المعدات والمباني مولّدة هندسيًا داخل اللعبة، ولم تُستورد نماذج فوتوغرافية عالية التفاصيل أو معدات مرخّصة.

## الاختبارات والحدود

تم التحقق من صحة JavaScript و17 حالة لحسابات الحفر والعقود والتحميل والتفريغ والخرسانة والاقتصاد والحفظ.
لم يتم تنفيذ اختبار صور WebGL فعلي داخل بيئة التطوير الحالية؛ يجب اختبار الرسومات على أجهزة حقيقية، وقياس FPS، قبل اعتبارها جاهزة للإصدار التجاري. الفيزياء مبسطة وليست محاكاة هيدروليك/تربة/هندسة معتمدة.
